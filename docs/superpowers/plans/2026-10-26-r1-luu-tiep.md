## Global Constraints
- **Nhãn** (VI → EN):
  - "Lưu" → Save
  - "Lưu · bài tiếp ›" → Save & next ›
  - "Lưu · việc tiếp ›" → Save & next task ›
  - "Lưu · em tiếp ›" (trang một em, hết bài của lượt) → Save & next student ›
  - "Lưu · đóng" → Save & close
  - "Bài tiếp ›" → Next ›
  - "Lớp tiếp: {lop} ›" → Next class: {lop} ›
  - "Việc tiếp ›" → Next task ›
  - "✓ Đã lưu" → ✓ Saved
  - "Đã xong phần của bạn · {phamVi}: đã lưu {n} bài" → Your part is done · {phamVi}: {n} saved
  - "Tiếp: {kyNang} · {ten}" → Next: {kyNang} · {ten}
  - "Ô còn trống — nhập điểm hoặc Vắng" → Empty — enter a score or mark Absent
- Không bao giờ ghi "cả lớp xong". Không đổi API, quyền, công thức điểm, luật N4 / N9 / N15.
- **Vắng giữ hành vi hiện tại** (ghi "-" rồi sang bài tiếp, toast có Hoàn tác).
- **Ô gõ trực tiếp lớp thường** (`ODiemThuong`) giữ Enter = xuống hàng — chỉ bỏ qua hàng chỉ đọc / không học.
- Dán Excel không đổi. Không đụng tệp P8 / P13 đang mở PR — gộp `origin/main` trước khi mở PR.

**Interfaces (Produces):**
```ts
export type ODiemConThieu = { required: boolean; canEdit: boolean; band: number | null; noShow?: unknown; progress: string };
export function conThieuFt(c: ODiemConThieu): boolean          // required ∧ canEdit ∧ band null ∧ !noShow ∧ progress ∉ {cancelled, absent} ∧ awaitingScore(progress)
export type ViTriO = { khoa: number; kyNang: string };           // khoa = attemptId (lưới) hoặc id dòng (Speaking chéo)
export function baiKeTiep(thuTu: readonly number[], conThieu: (v: ViTriO) => boolean, hienTai: ViTriO, kyNangToi: readonly string[]): ViTriO | null
```

  1. cùng kỹ năng, các hàng sau `hienTai`;
  2. cùng kỹ năng, các hàng trước `hienTai`;
  3. từng kỹ năng khác trong `kyNangToi` (đúng thứ tự cột), từ hàng đầu.
- Không bao giờ trả lại chính `hienTai`.
- [x] Viết phép kiểm ĐỎ trước:
  - BT-1: sau cùng cột.
  - BT-2: hết phía sau → vòng lên phía trước.
  - BT-3: hết L → ô R đầu tiên còn thiếu.
  - BT-4: bỏ ô có band.
  - BT-5: bỏ `required=false` (môn không học P8), `canEdit=false`, `noShow`, `progress='absent'|'cancelled'|'upcoming'`.
  - BT-6: khoá rời dữ liệu (lọc) → bỏ qua, thứ tự còn lại giữ.
  - BT-7: ô vừa có band ở dữ liệu mới → bỏ qua.
