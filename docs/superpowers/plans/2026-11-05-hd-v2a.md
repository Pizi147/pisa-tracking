### Task 1: Kiểu + hàm thuần + phép kiểm (TDD)
**Files:** `shared/huongDan/kieu.ts`, `shared/huongDan/index.ts`, `server/src/tests/prHd.tests.ts`
**Produces:**
- `ViecHd = { id; ten: Khoa; nhom: NhomHd; loiChinh: { man?: string; chu: Khoa; duong?: string; chi?: ChiChoToi }; loiTat?: string[]; tatThem?: Khoa[]; cung?: Khoa; buoc: Khoa[]; tuKhac?: string[]; chiGvcn?: true; chiS?: true }`
- `NhomHd = 'diem'|'case'|'hv'|'lich'|'duyet'|'khac'`; `ManHd` thêm `dangO?: { cau: Khoa; truoc?: DichHd; sau?: DichHd }`, `khongLam?: { ten: Khoa; den?: DichHd; cua?: Khoa }[]`, `panel?: 'case'|'nhap-diem'`; `MucHd` thêm `viec?: string` (bước riêng của việc X ở màn này).
- `HuongDan` thêm `lam?: ViecHd[]; tuan?: { nhip: Khoa; viec: string[] }[]; vaiKhac?: { ten: Khoa; cua: Khoa; tuKhac?: string[] }[]`; `viec` thành tuỳ chọn khi có `lam`.
- `viecOManNay(hd, manId): { viec?: ViecHd; muc: MucHd; tat: boolean }[]` — việc có `loiChinh.man === manId` hoặc `loiTat` chứa manId (thứ tự `lam`), bước thay bằng `muc.viec` nếu màn khai; rồi mục riêng.
- `locVai(hd, { gvcn, s })` bỏ việc `chiGvcn`/`chiS` khi cờ false. `timHd(hd, q, chu)` → `{ viec: ViecHd[]; muc: MucHd[]; vaiKhac }` (bỏ dấu, đầu từ, `tuKhac` khớp cụm). `manTheoId(hd, id)`.
- Phép kiểm mới: HD-LOI (mỗi `loiChinh.man`/`loiTat` là màn có thật; `duong`/Trước/Sau/`khongLam.den` khớp route `App.tsx` + `navOf` của tài khoản mẫu GV); HD-MOT (mỗi việc đúng một lối chính, id việc không trùng, `loiTat` không chứa màn lối chính); HD-TUAN (`tuan` chỉ trỏ việc có thật, mỗi việc 2–4 bước); HD-CO (GVBM `locVai` không còn việc GVCN; S); HD-TIM2 ("doi lop" → `de-xuat-chuyen-lop` + vai khác). HD-VIEC bỏ qua vai có `lam`.
