### Task N2: Quét theo mốc DB toàn hệ thống

**Interfaces — Consumes:** N1 (`layMoc`, bảng `moc_he_thong`). **Produces:**
```ts
// platform/mocHeThong.ts
export const QUET_DOC_MS = 60_000;
export function quetTheoMoc(khoa: KhoaQuet, homNay: string, fn: () => void): boolean;   // true = đã quét trong request này
export function xoaMocQuetSauGhi(): void;
export function moiMocQuet(m: MocHeThong | null | undefined): boolean;   // có mốc quét nào khác NULL (móc ghi khỏi tốn câu)
```
Luật `quetTheoMoc`: `nho('quet-moc:' + khoa + ':' + homNay, …)`. `m = layMoc()`; không có `m` → `fn()` (ngoài request có phiên). `q = m.quet[khoa]`: `q.luc && q.ngay === homNay && Date.now() - Date.parse(q.luc) < QUET_DOC_MS` → bỏ qua (0 câu).
